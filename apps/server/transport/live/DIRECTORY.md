# live 目录索引

直播会话接口

```text
live/  # 直播会话接口
├── DIRECTORY.md  # 本目录的直属文件与子目录索引（自动生成）
```

内容变更会刷新所在目录及祖先目录的索引指纹。运行 `npm run tree:check` 检查索引是否最新。
